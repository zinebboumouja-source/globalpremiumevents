Éditeur de mission

Remplissez la fiche d’un pays. L’aperçu montre la page et les 3 documents exactement comme ils seront publiés. Quand c’est prêt, copiez le code et collez-le dans missions/missions-data.js.

Partir d’une mission existante

Pour dupliquer une mission (ex. même format, autre pays), chargez-la puis modifiez.

1. L’essentiel

Pays, dates et statut. L’identifiant apparaît dans l’adresse de la page.

2. Événement d’ancrage

Le grand événement du pays sur lequel la mission s’appuie. Laissez le nom vide s’il n’y en a pas.

3. Contenu commercial

Une ligne = un élément. Les 3 forfaits, le comparatif et la traduction anglaise d’une mission chargée sont conservés : ils se modifient directement dans missions-data.js. Les champs « Forfait » ci-dessous servent aux missions à prix unique.

4. Programme

Un jour par bloc : le nom du jour sur la première ligne, puis une activité par ligne. Laissez une ligne vide entre deux jours.

5. Infos pratiques

Reprises dans la page et la note d’information.
